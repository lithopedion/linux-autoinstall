# 🎄 Xubuntu karácsonyra 🎄
Adományozott számítógépek automatizált Xubuntu 26 telepítése és konfigurálása Szeged környéki rászoruló gyerekeknek. Nyelvi modell közreműködésével két parancssor-szörnyeteg bash-szkript egyszerűsíti a beállításokat, a szoftvertelepítést és a Roblox (Sober) előkészítését. Gépenként majdnem 1-1 órát sikerült megtakaritani.
